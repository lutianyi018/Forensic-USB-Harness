# USB 连接历史分析

## 适用场景
需要确认某台 Windows 主机上 USB 存储设备的接入 / 拔出时间与设备序列号时。

## 输入
- 目标主机的 SYSTEM 注册表配置单元（system hive）、可选 setupapi.dev.log。
- 关注的时间窗口。

## 步骤
1. 用已注册的取证工具提取 USB 相关注册表键（`USBSTOR`、`Enum\USB`、`MountedDevices`）。
2. 汇总每台设备的首次 / 末次接入时间与序列号。
3. 与文件系统时间线交叉核验，剔除无关设备。
4. 输出设备清单、时间线，以及每条的来源证据路径。

## 约束
- 原始证据（固证区）只读；解析与汇总产物写入工作区。
- 结论分级：区分事实与推断，时间接近不等于存在传输行为。
