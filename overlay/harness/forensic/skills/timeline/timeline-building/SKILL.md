# 时间线重建

## 适用场景
需要把文件系统、注册表、事件日志、浏览器等多来源时间戳合并为一条可读时间线时。

## 步骤
1. 对每个来源先各自标准化时间（统一时区，优先 UTC）。
2. 归一为「时间 / 来源 / 主体 / 动作 / 证据路径」五元组。
3. 合并排序，标注冲突与缺口。
4. 标出与研究目标相关的时间窗与异常点。

## 输出
- 机器可读：`timeline.csv`（写入工作区）。
- 人可读：关键事件摘要 + 每条的证据引用。

## 约束
- 时间接近只是线索，不构成因果；结论分级标注。
